# Screenshots

This directory is for application screenshots.

## How to Capture Screenshots

Run the application and take screenshots of each major section:

```bash
streamlit run app.py
```

Recommended screenshots:
1. `overview.png` — Overview dashboard with loaded data and metrics
2. `data_explorer.png` — Data Explorer showing class distribution
3. `detection_lab.png` — AI Detection Lab after training
4. `confusion_matrix.png` — Model Evaluation confusion matrix
5. `threat_analysis.png` — Threat Analysis with risk gauge
6. `security_insights.png` — Feature importance chart
7. `threat_intelligence.png` — Educational threat intelligence section

Screenshots are NOT committed to the repository automatically.
Add them after capturing from the running application.
